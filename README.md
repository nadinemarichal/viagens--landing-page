# EuroVillage - Landing Page de Viagens

![Banner EuroVillage](https://images.unsplash.com/photo-1519681393784-d120267933ba?ixlib=rb-4.0.3&auto=format&fit=crop&w=1170&q=80)

Landing page responsiva para uma agência de viagens especializada em vilarejos europeus, desenvolvida como parte de um projeto de aprendizado em desenvolvimento web.

## 📋 Funcionalidades

- **Navegação responsiva** com menu hamburger para dispositivos móveis
- **Banner principal** com overlay de texto e call-to-action
- **Seção TripMe** - Apresentação dos destinos com cards interativos
- **Seção MeetUs** - Informações sobre a empresa e sua missão
- **Seção Advice** - Dicas de viagem com ícones ilustrativos
- **Seção de Contato** - Formulário funcional e informações de contato
- **Rodapé completo** com newsletter e links rápidos
- **Scroll suave** entre seções
- **Animações e transições** nos elementos interativos

## 🛠️ Tecnologias Utilizadas

- HTML5 semântico
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript Vanilla (para interatividade mínima)
- Font Awesome (ícones)
- Google Fonts (Playfair Display e Raleway)
